# 授权中心0.2.0

新增统一授权接入信息签发和复制交付。包含中心地址、公钥、实例ID、HTTPS地址及一次性激活信息，配套管理端1.9.66支持粘贴激活。未激活授权可重新生成，旧信息自动失效；已激活实例仍按续期及部署迁移处理。

沿用现有数据库、运营账号和签名身份，不执行重新初始化，不自动激活存量代理。保留官方客户端授权策略与验证码登录兼容能力。先升级授权中心，再发布配套管理端。

后端28项、前端8项、类型检查、架构检查、构建及双仓隔离接入验证通过。源码标签与生产部署分别核验。
